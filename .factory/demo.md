# Demo sandbox

- URL: `https://quiet-dictation-bridge.sociobot.in/?demo=1`
- Entry point: choose **Try it with sample data** on the first screen.
- Sample: three realistic received phrases across Project notes and Daily admin.
- Storage: IndexedDB database `demo:quiet-dictation-bridge`. Real data uses
  `quiet-dictation-bridge`, so demo import, clear, and reset never read or write
  real history.
- Reset: choose **Reset demo** in the persistent demo banner.
- Exit: choose **Start for real**. The demo database remains separate and is
  never copied into real history.
